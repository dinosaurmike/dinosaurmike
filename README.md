**Human–AI interaction.** &nbsp;Direct manipulation, ghost overlays, live verification and supervisory controls, not another chat box.<br>
**Legible state.** &nbsp;What the system is doing, what changed, and how sure it is.<br>
**Code-first.** &nbsp;React, TypeScript, Three.js, SVG and LLM APIs, with deterministic code where precision matters.<br>
**Open source.** &nbsp;[Shellfall](https://github.com/dinosaurmike/Shellfall) and [Orbit](https://github.com/dinosaurmike/Orbit) are MIT-licensed, from the 60 Hz falling-sand engine to the Android app and neck firmware. The code for [IdeaBox](https://github.com/dinosaurmike/IdeaBox), [ShelfLife](https://github.com/dinosaurmike/ShelfLife), [TimberCraft](https://github.com/dinosaurmike/TimberCraft), [Toybox Siege](https://github.com/dinosaurmike/ToyboxSiege), [Garage Studio](https://github.com/dinosaurmike/GarageStudio), [SolarBreak](https://github.com/dinosaurmike/SolarBreak), [DayMark](https://github.com/dinosaurmike/DayMark) and the [Bay Area Games](https://github.com/dinosaurmike/BayAreaRealEstateGames) is here to read.
